# Chart Widget Specifications for LawalX Project

I'll provide corrected and detailed widget specifications for each chart type, aligned with your Stacked Bar Chart widget pattern.

---

## 1) **STACKED BAR CHART** ✓
**Status:** Already designed (reference template)

**Widget Controls:**
- Title input
- Dataset selector dropdown
- X-field selector (auto-populate from dataset)
- Series Manager (min 2, max 5):
    - Series label input
    - Color picker
    - Include in stack toggle
    - Drag-to-reorder handle
- Mode toggle: Absolute / 100%
- Aggregate function dropdown: Sum / Count / Avg
- Sort categories dropdown: Alphabetical / By Total / Custom
- Values display toggle: Raw / Percentage
- Legend toggle + Position selector: Top / Bottom / Left / Right
- Tooltip toggle: Raw + Percentage
- Filters section: Field filters + Date range picker
- Accessibility label input

## **General Widget Features (All Charts):**

1. **Header Section:**
     - Chart title input field
     - Chart type display (read-only)
     - Preview toggle (eye icon)

2. **Data Section:**
     - Dataset selector
     - Field selectors (context-dependent)
     - Filter panel (collapse/expand)

3. **Appearance Section:**
     - Color pickers (organized by element)
     - Legend controls
     - Label toggles
     - Position selectors

4. **Advanced Section (Collapsible):**
     - Animation toggles
     - Custom CSS/styling
     - Accessibility options
     - Tooltips configuration

5. **Footer Section:**
     - Save/Cancel buttons
     - Reset to defaults button
     - Preview/Live toggle

---

This structure aligns with your Stacked Bar Chart template and provides comprehensive, organized controls for your UI/UX designer.
